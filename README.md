#kiro instruction of the digital library
Here are all the prompt instructions in descriptive format — exactly what you would tell an AI assistant to build this website step by step.

🏛️ Digital Library — All Prompt Instructions (Descriptive Format)
PROMPT 1 — Project Start
Build me an AI-powered public information assistant website called "Digital Library" as a single HTML file. It should help citizens find government services, resources, and opportunities through a chat interface. No backend, no API, no frameworks needed — everything should run in the browser. The page title should be "Digital Library – Your Public Services Assistant".

PROMPT 2 — Background
Make the background of the website an animated multicolour light-toned gradient. Use soft pastel colours — sky blue in the top-left corner, lavender purple in the top-right, mint green in the bottom-right, warm peach in the bottom-left, and soft periwinkle in the centre. The colours should slowly shift and breathe using a CSS animation that runs continuously. The background must be fixed so it stays in place while the user scrolls. Make it easy and comfortable on the eyes.

PROMPT 3 — Header
Create a header at the top of the page. The header should have a frosted glass effect with a light white background. Place the website name "Digital Library" in the exact centre of the header with a large bold font. Use a gradient colour for the title text going from cyan to purple to pink. Add the book emoji 📚 above the title and a small subtitle below it that says "AI-powered access to public services, resources and opportunities" in a soft blue colour. The header should have a soft shadow below it.

PROMPT 4 — Header Buttons
Add two buttons to the header. First, place a Wikipedia button on the right side of the header. It should show the Wikipedia favicon icon and the word "Wikipedia". When clicked it should open wikipedia.org in a new browser tab. Second, add a glowing amber-coloured button on the left side of the header labelled "⚡ Tech Skills". This button should pulse with a glowing animation to draw attention. When clicked it should open a popup panel showing trending tech skills.

PROMPT 5 — Page Layout
Divide the main content area into two columns side by side. The left column should be a fixed-width sidebar about 260 pixels wide containing the category navigation cards. The right column should take up all remaining space and contain the chat interface. Both columns should sit inside a centred container with a maximum width of 1200 pixels and comfortable padding around them.

PROMPT 6 — Sidebar Category Cards
Add ten category cards in the left sidebar. Each card should have a unique attractive colour, an emoji icon, a bold label, and a small subtitle describing what it covers. The cards should have rounded corners, a subtle shadow, and a smooth hover animation that slides them slightly to the right and brightens their colour with a glow effect. Here are the ten categories with their colours — Healthcare in rose red, Education in warm amber, Housing in sky blue, Employment in emerald green, Legal Aid in purple, Food Assistance in orange, Transportation in electric blue, Explore Subjects in indigo, Opportunities in teal green, and Tech Skills in amber orange. When any card is clicked it should trigger the relevant action in the chat.

PROMPT 7 — Stats Box
At the bottom of the sidebar below all the category cards, add two small stat boxes side by side. The first box should show "50+" with the label "Services Covered". The second should show "24/7" with the label "Available". Both boxes should have a frosted glass background, a purple-tinted border, and a bold coloured number.

PROMPT 8 — Quick Chips
At the top of the main content area, add a row of small clickable shortcut buttons called chips. Each chip is a pill-shaped button with a light glass background and a purple border. When hovered they should glow and change colour. Add chips for the most common queries — Apply for Medicaid, College Scholarships, Emergency Housing, Unemployment Benefits, Food Banks, Free Legal Help, Explore Subjects, and Opportunities. When a chip is clicked it should automatically send that question into the chat.

PROMPT 9 — Chat Window
Create a chat window below the chips. It should have a frosted glass white background, rounded corners, a soft border, and a subtle shadow. The chat window should be scrollable and show a conversation between the user and the AI assistant. User messages should appear on the right side with a purple-to-indigo gradient bubble. Bot messages should appear on the left side with a white bubble and a light purple border. Each message should have a circular avatar — a robot emoji for the bot and a person emoji for the user. New messages should fade in smoothly with a slide-up animation. Add a welcome message from the bot when the page first loads.

PROMPT 10 — Typing Indicator
When the bot is processing a response, show a typing indicator in the chat. It should look like three small dots bouncing up and down one after another, inside a bot message bubble. The animation should repeat continuously until the real response appears. Remove the typing indicator before showing the actual response.

PROMPT 11 — Input Bar
Below the chat window, add a message input bar. It should span the full width, have a frosted glass white background, rounded corners, and a purple border that glows when the user clicks inside it. Inside the bar there should be a text input field on the left with placeholder text saying "Ask about any public service or resource..." and a send button on the right. The send button should have a purple-to-indigo gradient, bold white text, and a glow shadow. When the user presses the Enter key or clicks the send button the message should be sent. The send button should be disabled while a response is being generated.

PROMPT 12 — Chat Intelligence
Make the chat smart using keyword detection. When the user types a message, scan it for keywords and route it to the right category. If the message contains words related to health, medicine, doctor, or clinic — show healthcare resources. If it contains school, college, scholarship, or FAFSA — show education resources. If it contains housing, rent, shelter, or eviction — show housing resources. If it contains job, work, employment, or career — show employment resources. If it contains legal, lawyer, court, or rights — show legal aid resources. If it contains food, hungry, SNAP, WIC, or groceries — show food assistance resources. If it contains bus, transit, or transport — show transportation resources. If it matches patterns like "tell me about", "what is", "explain", or "what are" followed by a topic — treat it as a subject search and show web sources. If nothing matches, give a helpful fallback reply.

PROMPT 13 — Resource Cards in Chat
When the bot responds to a category question, display the resources as small cards inside the chat bubble instead of plain text. Each resource card should show an emoji icon on the left, a bold title, a short description, and a clickable link that opens the official website in a new tab. The cards should have a light background, a subtle border, and a hover effect that highlights the border. At the bottom of each response add a tip reminding the user they can call 211 to reach local social services.

PROMPT 14 — Subject Explorer Panel
When the user clicks "Explore Subjects" from the sidebar or chip, open a dedicated search panel inside the main area above the chat. This panel should have an indigo-tinted frosted glass background and a purple border. Inside the panel show a heading, a text input field where the user can type any subject, and a search button. When the user searches a topic, close the panel and show results in the chat. The results should contain six cards — one each for Wikipedia, Google Search, Khan Academy, Google Scholar, YouTube, and Internet Archive. Each card should have a direct link that searches for that topic on the respective platform. Also add ten quick-topic shortcut tags inside the panel for popular subjects like AI, Climate Change, World War II, Quantum Physics, Space Exploration, Democracy, Blockchain, Psychology, Human Anatomy, and Renewable Energy.

PROMPT 15 — Opportunities Panel
When the user clicks "Opportunities" from the sidebar or chip, open a green-themed panel inside the main area. This panel should show latest opportunities dedicated to youth and students. Add filter tabs at the top to filter by All, Tech, Scholarships, Internships, Competitions, and Programs. Display twelve opportunity cards in a two-column grid. Each card should show an emoji, the opportunity name, a short description, a coloured status badge showing whether it is New, Hot, Free, or Open, and two links — one to apply and one to read more. Include real opportunities like Google Summer of Code, Gates Scholarship, NASA Internship, GitHub Student Developer Pack, MIT Hackathon, UN Youth Volunteer Programme, Microsoft AI Skills, Chevening Scholarship, CERN Summer Programme, and Google Career Certificates.

PROMPT 16 — Tech Skills Popup
Build a popup panel that appears in the top-right corner of the screen. It should slide down smoothly when opened. The popup should have a white frosted glass background, an amber-coloured border, and a dark overlay behind it that blurs the rest of the page. The header of the popup should say "⚡ Trending Tech Skills 2025" with an amber gradient background. Add filter tabs for All, AI, Web, Data, Cloud, Cyber, and Mobile. Show twelve skill cards, two for each category. Each card should show the skill name, an emoji, a coloured category badge, a short description of why it is valuable in the job market, and two links — one to a free learning resource and one to see job market trends. This popup should automatically open one second after the page loads, and close when the user clicks the X button or the dark overlay.

PROMPT 17 — Fallback Responses
When the user types something that does not match any category, handle these special cases. If the message is a greeting like hi, hello, or hey — reply with a friendly introduction. If the message contains thank or thanks — reply with an acknowledgement and remind them to call 211. If the message mentions 211 — explain that it is a free 24/7 helpline that connects people to local social services. If the message contains emergency, urgent, or crisis — provide the numbers 911, 211, and 988 for the Suicide and Crisis Lifeline. If the message mentions veteran or military — point to VA.gov. If it mentions disability — point to SSA.gov, ADA.gov, and vocational rehabilitation. If it mentions immigrant or immigration — point to USCIS, ImmigrationAdvocates.org, and ACLU immigrant rights. For anything else not matched, show a friendly guide message listing all available categories.

PROMPT 18 — Colours for Each Category
Give each category card its own unique colour theme that is consistent throughout. Healthcare should use rose red tones. Education should use warm amber and gold tones. Housing should use sky blue tones. Employment should use emerald green tones. Legal Aid should use purple and violet tones. Food Assistance should use orange tones. Transportation should use electric blue tones. Explore Subjects should use indigo tones. Opportunities should use teal and mint green tones. Tech Skills should use amber and orange tones. Every card should have a matching gradient background, a coloured border, and a glow box shadow on hover that matches its colour.

PROMPT 19 — Responsive Design
Make the website fully responsive for mobile and tablet screens. On screens smaller than 768 pixels wide, stack the sidebar above the main content instead of side by side. Make the sidebar cards wrap into a horizontal row. Reduce the header title font size. Shrink the header buttons so they do not overlap the title. Make the tech skills popup take up nearly the full screen width on mobile. Ensure the chat window and input bar work well on small screens.

PROMPT 20 — UI Polish and Final Details
Add these finishing touches to make the website look and feel premium. Add a custom scrollbar with a purple thumb colour that glows on hover. Make all card hover transitions smooth using cubic-bezier easing. Add a backdrop blur and frosted glass effect to the chat window, input bar, all panels, and the skills popup. Give the send button a glow shadow that intensifies on hover. Make the category card hover animation slide the card slightly to the right and scale it up very slightly. Ensure all external links open in a new browser tab with rel="noopener" for security. Add smooth fade-in animations to every new chat message. Make the input bar border glow purple when the user clicks inside it. Ensure the typing indicator dots bounce with a staggered delay between each dot.

PROMPT 21 — Name Change (Optional)
Change the name of the website from CivicAI to Digital Library. Update the browser tab title, the header title, the welcome message in the chat, and all greeting responses to use the new name Digital Library. Also change the header logo emoji from the building emoji to the books emoji 📚.
